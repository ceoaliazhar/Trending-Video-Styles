# Story Engine: 5 Acts

> Reference first: `GOLD-STANDARD.md`. Reveals come from the villain's mouth; flashback = 1 date + 1 science line + 1 image. The tables below are guidance (L21–L22).

**Law:** the `{ITEM}` is the EVIDENCE, never the hero. The viewer reaches the offer before realizing it's an ad.

| Act | Job | Must contain |
|---|---|---|
| 0. Cold open | Drop viewer mid-scene | Victim/villain says the myth aloud + visible stakes. No narrator, no logo. |
| 1. Interrogation | Challenge the myth + open the loop | 5 sub-beats, in order: **Question** ("Who told you?") → **Defense** (victim/villain cites authority) → **Teaser bomb** (one shocking, specific fact, NO explanation) → **Disbelief** (victim pushes back) → **Silencer + "Watch."** (narrator cuts them off; the flashback must pay off the teaser) |
| 2. Flashback | Prove it | "Place, Year." dateline · one plain science/history line · escalation ("Then… then…") · villain interrupts |
| 3. Proof test → Verdict | Climax + flip | A test the villain can't pass (pick from `proof-test-bank.md`, rotate types) · verdict flips the myth (verdict = title) and exposes the seller, never prescribes behavior · victim's realization |
| 4. Ritual + Offer | Resolve | `{SIGNATURE_LINE}` → `{OFFER}` as the consequence of the lesson |

For `{GOAL}` = organic: replace the offer with a binary-choice identity close (reference pattern) + `{FUNNEL}` link in the description.

## Emotional layer (required, see cast-kit.md)
Max 3 speakers, 1 relationship, 1 reveal. 3 beats: show the bond (Act 0) · face at stake (Act 1) · small repair / own choice (Act 3–4).

## Anti-ad rules
1. Frame 1 = dialogue mid-action, never a product shot.
2. One myth per episode.
3. Villain sells the shortcut; the viewer roots against the seller.
4. A date or number every 5–8s.
5. No sale language before the last 6s.
6. Series, not ads: same cast, numbered cases, same ritual.
7. Narrator concedes the trust attack ("Don't trust me either.").

## Myth patterns (generalized)
| Pattern | Template |
|---|---|
| The label/claim lie | "It says X." → "Who wrote that?" |
| The number lie | "Everybody knows it's N." → "Who picked N?" |
| The price lie | "Same thing, cheaper." → "Same name, different thing." |
| The authority lie | "Experts say." → "Which experts? Paid by whom?" |
| The ritual lie | "Everyone does it on day X." → "Who invented day X?" |
| The purity/quality lie | "It's pure." → "Pure when? Pure when it reaches you?" |

## Title formula
"The X Was Never the Y" · "They [did X] Because…" · "Who Really [verb] Your X?"
