# Language Rules (`{REGISTER}` = "scientific for common folks" by default)

1. Sentences ~6 words. Fragments OK.
2. Dialogue in Acts 0–1, narration in Act 2, "you" in the verdict.
3. One science idea per line, in kitchen words ("It's a chain. Heat breaks chains.").
4. Any technical term gets an everyday translation in the same line, or it's cut.
5. Every claim is dated history or a verifiable process fact. **Use the exact verb the source supports** (invented / popularized / first published / funded / sold). The script may not upgrade it ("popularized" never becomes "invented").
6. Datelines open beats: "Place, Year."
7. Numbers specific and spoken naturally.
8. Each character has a voice: narrator slow/certain, villain fast/slick, victim nervous/curious.
9. Captions: one bold keyword per line (a noun).
10. `{CLAIM_LIMITS}` banned-word list lives in the project config.
