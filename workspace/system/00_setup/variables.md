# Variables

Fill these in `projects/<NAME>/config.md`. Every system file references them as `{VARIABLE}`.

| Variable | What it is | Example (fictional coffee brand) | Default |
|---|---|---|---|
| `{BRAND}` | Client brand | Northwind Roasters | — |
| `{ITEMS}` | Products/topics, one episode each | Light roast, Single origin, Cold brew | — |
| `{CATEGORY}` | Market category | Specialty coffee | — |
| `{GOAL}` | Ad (conversion) or organic (reach) | Ad | Ad |
| `{OFFER}` | What the viewer gets | Up to 30% off | — |
| `{OFFER_DEADLINE}` | Urgency date | Black Friday weekend | none |
| `{ACCESS_MODEL}` | Open store / gated / lead form | Gated researcher login | Open |
| `{PLATFORMS}` | Where it runs | Facebook, Instagram | Reels/Shorts/TikTok |
| `{MARKET}` | Country/region | US | — |
| `{AUDIENCE}` | Who buys + why | Personal-use researchers, price/trust anxious | — |
| `{COMPETITORS}` | 4–8 competitor URLs | 5 coffee subscription sites | — |
| `{REFERENCE_CHANNEL}` | Format to reverse-engineer | @QuietWolfz | @QuietWolfz |
| `{REGISTER}` | Language level | Scientific for common folks | same |
| `{LENGTH}` | Script length | 60s | 60s |
| `{CLAIM_LIMITS}` | What can't be said | No body/outcome/dosing claims | Platform defaults |
| `{CAST}` | Narrator / villain / victim | Crow / Magpie / Squirrel | from world-builder |
| `{SIGNATURE_LINE}` | Ritual close | "Don't trust the label. Don't trust me. Read the batch." | from world-builder |
| `{STACK}` | Production tools | ElevenLabs VO, AI visuals, code-driven edit | — |
| `{CLIENT_FEEDBACK}` | Known likes/dislikes | "Too technical" | — |
