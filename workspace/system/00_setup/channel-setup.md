# Step 0: Brand Style Setup (once per brand) [simplified, see L19]

Only the narrator, silencer, ritual close and visual style are fixed per brand (see `03_engine/cast-kit.md`). Everything below is OPTIONAL, only for a brand that explicitly wants a recurring mascot series.

---


Every card reuses one world. Without it the engine invents a new cast per card, and the series never builds recognition.

1. Run `system/03_engine/universe-builder.md` → fill `projects/<NAME>/universe-bible.md` (template `system/05_templates/universe-bible-template.md`): place, rules, narrator backstory, recurring cast (character-engine), relationship web (relationship-engine).
2. Lock: narrator · villain archetype · victim archetype · setting · flashback device · silencer ("Shh. Watch.") · ritual close.
3. Per card, cast the **villain and victim species/role to fit the topic** (e.g. fox diner owner for breakfast), but the **narrator, setting, silencer and ritual never change**.
4. No universe bible = the engine stops and asks to run Step 0.
5. After each episode, append to the bible's "Series memory" (what changed between characters, what backstory was revealed).
