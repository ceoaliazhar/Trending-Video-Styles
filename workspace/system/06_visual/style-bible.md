# Style Bible (once per brand)

Write two **anchors**: fixed sentences pasted at the end of every prompt.

## How to build the anchors
| Field | Decide | Rule |
|---|---|---|
| Medium | e.g. hand-painted gouache, ink, clay, paper cut-out | Must NOT match the reference channel's look |
| Era / book style | e.g. 1950s picture book | One era only |
| Palette | 2 main colors + 1 accent | Tie colors to the story's theme |
| Light | Number and color of light sources | Fewer = more mood |
| Texture | paper grain, film grain, brush strokes | Same in every shot |
| Format | Vertical 9:16 | Always |

**Anchor A (present scenes):** medium + era + palette + light + texture + format.
**Anchor B (flashback):** a clearly different look (e.g. sepia ink drawing) so the viewer always knows "this is the past". **Grade rule (measured on reference):** everything desaturated except **one accent color** on the element that matters.

## Template
```
ANCHOR A: [medium], [era] picture-book animation, [palette], [light], [texture], anthropomorphic animal characters, vertical 9:16, no text, no subtitles.
ANCHOR B: animated [flashback medium] on [surface], [palette], hand-drawn line art coming alive, vertical 9:16, no text.
```

## Theme → palette ideas
| Story theme | Palette |
|---|---|
| Heat / spoilage vs safe storage | cold ink-blue + one hot orange source |
| Money / greed | deep green + gold |
| Health myths / food | cream + tomato red |
| Time / history | sepia + soot black |
