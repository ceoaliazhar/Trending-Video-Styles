# Feedback Protocol

1. Log every client comment verbatim in `projects/<NAME>/feedback.md` (date · script · quote).
2. Classify: wording / structure / tone / fact / strategy.
3. Fix in a new version (`_v2`); never overwrite.
4. If the same kind of feedback appears twice, or once from a client rejection, promote it to `lessons-log.md` and update the system file.
5. After launch: log results (hook rate, hold rate, CTR, CPA) per script; winners' patterns go into `selection-method.md`.
