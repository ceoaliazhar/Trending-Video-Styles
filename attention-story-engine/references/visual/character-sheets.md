# Character Sheets (Flow Characters)

The #1 production risk is characters drifting between shots. This is the fix.

## For each character
1. **Locked description** (one sentence, 25–40 words): species, age, build, 2–3 clothing items, 1 signature prop, eye color. Never paraphrase it later.
2. **Voice line**: age, pace, texture, accent (e.g. "deep, slow, warm older male voice, slight rasp").
3. **Reference image** in Nano Banana Pro:
   ```
   Character reference sheet of [LOCKED DESCRIPTION]. Full body front view, neutral pose, plain light grey background, even studio light. [ANCHOR A without the scene/light parts]. No text.
   ```
   Make 4, pick the best, then generate 2 more views (three-quarter, close-up face) from it with "same character" edits.
4. **Save as a Flow Character** named exactly as in the script (`Crow`, `Magpie`…). Add the voice reference if available (voice refs only work with Ingredients-based generations).
5. **Test shot:** one close-up speaking line. Fix the sheet before going further if the face or voice drifts.

## Rules
- Max 3 speaking characters per script (cast kit).
- Distinct silhouettes: you should tell them apart as black shapes.
- Plain/segmented backgrounds on references help Flow lock the subject.
