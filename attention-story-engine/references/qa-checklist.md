# QA Checklist (guidance, not a form, see L21)

**Principle check:** label every beat with the principle it activates (P1–P13, `references/attention-principles.md`). A beat with no principle gets cut.

**Final test, always:** read it aloud next to `examples/gold-standard.md`. If it sounds assembled or like a lecture, rewrite. This test overrides every box below.


## Hard gates (all must pass)
- [ ] Word count matches `{LENGTH}` (beat-maps)
- [ ] Frame 1 = dialogue mid-action
- [ ] 5 conflict layers present, a "no" ~every 10s
- [ ] No sale words before the last 6s
- [ ] Signature line + offer close at the end
- [ ] Every fact sourced in the Fact Log, and the script uses the source's exact verb (no "popularized" → "invented")
- [ ] Verdict exposes the seller; it never tells the viewer what to do with their body/money
- [ ] Brand style fixed pieces used (narrator, silencer, ritual, look)
- [ ] Max 3 speaking characters, 1 relationship, 1 reveal
- [ ] Voice test: names covered, every speaker still identifiable (trait + tell visible)
- [ ] 3 emotion beats: bond, face at stake, own-choice repair
- [ ] Trend card has a "use by" date that hasn't passed
- [ ] Proof-test type differs from the previous episode's
- [ ] Interrogation has all 5 sub-beats (question, defense, teaser bomb, disbelief, "Shh. Watch.")
- [ ] Nothing breaks `{CLAIM_LIMITS}`
- [ ] Nothing copied from `{REFERENCE_CHANNEL}`
- [ ] Every lesson in lessons-log respected
